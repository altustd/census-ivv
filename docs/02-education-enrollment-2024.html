This differs from the ACS education enrollment question, which asks about enrollment at any time in the past 12 months — a broader definition that produces higher enrollment counts.

Census API — CPS October School Enrollment 2024 
import os
import requests
import pandas as pd

API_KEY = os.getenv("CENSUS_API_KEY", "")
YEAR = 2024
DATASET = "cps/school/oct"

# Check available variables for this dataset/year
var_url = f"https://api.census.gov/data/{YEAR}/{DATASET}/variables.json"
r = requests.get(var_url, timeout=30)

if r.status_code == 200:
    variables = r.json()["variables"]
    # Filter to school enrollment variables
    enroll_vars = {k: v for k, v in variables.items()
                   if "ENROLL" in k.upper() or "SCHOOL" in k.upper()
                   or "PESC" in k.upper()}
    for k, v in sorted(enroll_vars.items()):
        print(f"{k:25s}  {v.get('label', '')}")
else:
    print(f"Dataset not yet available for {YEAR}: HTTP {r.status_code}")
Pull national enrollment totals 
# National enrollment by school level
# PESCHLVL: school level (nursery, K-12, college)
# PESCHFT: full-time vs part-time college enrollment

params = {
    "get": "PESCHLVL,PWSSWGT",   # school level + person weight
    "for": "us:1",
    "key": API_KEY,
}

base = f"https://api.census.gov/data/{YEAR}/{DATASET}"
r = requests.get(base, params=params, timeout=30)
r.raise_for_status()
data = r.json()
df = pd.DataFrame(data[1:], columns=data[0])

# Convert to numeric
df["PESCHLVL"] = pd.to_numeric(df["PESCHLVL"])
df["PWSSWGT"] = pd.to_numeric(df["PWSSWGT"])

# School level codes (check variables.json for exact mapping)
level_map = {
    1: "Nursery/preschool",
    2: "K–12",
    3: "College/university",
    -1: "Not enrolled / not applicable",
}

df["level"] = df["PESCHLVL"].map(level_map)

totals = (df[df["PESCHLVL"] > 0]
          .groupby("level")["PWSSWGT"]
          .sum()
          .div(1000)   # to thousands
          .reset_index()
          .rename(columns={"PWSSWGT": "enrolled_thousands"}))

print(totals.to_string(index=False))

4.5 Observations

Things to note while pulling this data — potential seeds for future projects:

1. ACS vs. CPS enrollment gap The ACS B14001 group reports school enrollment for the past 12 months; the CPS October supplement reports current enrollment. The ACS count is consistently higher. Quantifying this gap by level and geography is a clean methodological note.

2. Geographic disaggregation The CPS is designed for national and state-level estimates. For county or tract-level enrollment, the ACS 5-year is the right product. Mapping K–12 enrollment rates at the county level from ACS 5-year data (B14003) is a natural visualization project.

3. Enrollment trends The CPS October supplement goes back to 1947. A time-series of college enrollment rates by age group and sex is available with no additional data acquisition beyond API calls.

4. College enrollment by institution type The CPS asks whether enrolled at 2-year or 4-year institution (PESCHLVL values distinguish these). Tracking the 2-year vs. 4-year split over time, especially post-2020, may be worth a dedicated note.
